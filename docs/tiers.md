# Prism 免费与企业切分

付费锁组织能力，不锁拆图次数。

## 免费

可在 Codex、Grok、WorkBuddy 个人版、腾讯 SkillHub 使用：

- 单张图拆成类型化字段
- 编译成 GPT Image 用的自然语言提示词
- 本机词卡库与五轴抽取
- 色卡字段与失败风险句
- 源码与演示素材

## BF Labs 定制 WorkBuddy 企业版

只有企业席位加 BF Labs 实施才交付：

- 公司级词卡 / 色卡 / 提示词库，部门共用
- 品牌锁：官方色、禁用词、已批准版式
- 接到客户素材盘、知识库或业务系统的 MCP
- 权限：谁能拆、谁只能用已批准词卡
- 审计：谁拆了哪张图、导出给了谁
- 定时数字员工：例如每周竞品视觉简报

## 明确不作为付费点

- 反推积分、高精度加价、动作参考按次收费
- 开卡包动画、云端画函
- 「更像 Viko」的复刻分数

## 对外一句话

免费教会一个人拆图；企业版让全公司用同一套视觉合同，并接进他们自己的系统。
