# 编译顺序

内部用 JSON seed。给模型的成品必须是自然语言，禁止 Stable Diffusion 词汤，禁止把 JSON 当用户可见输出。

顺序：

1. 画幅与载体
2. 核心风格合约 / 媒介质感
3. 构图、机位、主体占位
4. 主体或脸部锁定
5. 材质、服装或印刷
6. 光线、色彩系统、清晰度地图
7. 把载体/媒介、风格合约、主体/脸、视线或姿态、线面、海报文字再收成一句「必须守住」
8. 以「避免」开头的失败风险

规则：

- 每个短语必须改变画面。删掉「精美」「高质量」「8k」。
- 脸部风格与总风格分开写。
- 色卡只写颜色职责和比例，不写 hex 堆砌除非用户要。
- 动作只写姿态、接触、重心，不把参考图的身份带进去。
- 看不清的字写成「不可辨小字」，不许编品牌和价格。
